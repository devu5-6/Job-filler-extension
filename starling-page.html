About the Role

Job Title: Python & GenAI Developer

Our values are a part of everything built here, including careers.

About the Role

Are you passionate about Python and excited to build intelligent, scalable digital solutions using Generative AI? Kick-start your career with us and work on real-world projects powered by modern AI technologies in Jaipur.

Key Responsibilities

  • •Develop and maintain backend applications using Python.
  • •Build and optimize RESTful APIs with Django, Flask, or FastAPI.
  • •Develop GenAI applications powered by LLMs.
  • •Build AI workflows and intelligent agents using LangChain and LangGraph.
  • •Implement RAG pipelines and semantic search using VectorDatabases.
  • •Work with SQL and NoSQL databases to manage data efficiently.
  • •Integrate AI models, APIs, and third-party services.
  • •Collaborate with frontend developers, designers, and project teams.
  • •Write clean, efficient, testable, and well-documented code.
  • •Participate in testing, debugging, and performance optimization.

Required Skills & Qualifications

  • •0–1 Years of experience (Immediate Joiners preferred).
  • •Strong foundation in Python programming.
  • •Familiarity with Django, Flask, or FastAPI basic knowledge is welcome.
  • •Understanding of MySQL, PostgreSQL, or MongoDB.
  • •Basic knowledge of REST APIs and integrations.
  • •Awareness of Generative AI concepts, LLMs, prompt engineering, and RAG.
  • •Familiarity with LangChain, LangGraph, or vector databases such as Pinecone, Chroma, FAISS, Weaviate, or Qdrant is a plus.
  • •Familiarity with Git is an advantage.
  • •A strong problem-solving mindset and eagerness to learn.

Preferred Skills

  • •Familiarity with LangChain, LangGraph, or vector databases (Pinecone, Chroma, FAISS, Weaviate, Qdrant).
  • •Familiarity with Git and GitHub collaborative workflows.
  • •Exposure to cloud deployments (AWS) or containerization.

Why Join Starling Elevate

  • •Build practical AI-powered products and scalable backend systems.
  • •Work on diverse and challenging real-world projects.
  • •Learn through continuous mentorship and hands-on experience.
  • •Gain exposure to modern AI frameworks, LLMs, and vector databases.
  • •Grow in a supportive and innovation-driven work culture.
